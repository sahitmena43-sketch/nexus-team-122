Slash Commands (/)

  • /bot - Basic bot info
  • /botinfo - Detailed bot stats
  • /serverinfo - Server info
  • /userinfo [@user] - User info
  • /clear <amount> - Delete messages (Admin)
  • /say <message> - Bot says something
  • /dm_support <message> - Message support
  • /guide - Full bot guide (Admin)
  • /lock [#channel] - Lock channel (Mod)
  • /unlock [#channel] - Unlock channel (Mod)
  • /warn <user> [reason] - Warn user (Mod)
  • /unwarn <user> - Remove warning (Mod)
  • /seewarns [user] - See warnings
  • /ticket - Create ticket panel (Admin)
  • /createchannels - Create all bot channels (Admin)
  • /activity - Activity log (Owner)
  • /help - Show this list
