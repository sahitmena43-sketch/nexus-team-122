The official user verification page for NEXUS TEAM.

Verification System: Active

Linked Roles Verification

This is the NEXUS TEAM verification endpoint. Discord uses this URL to verify users and let them link roles to their accounts.

How Does Verification Work?

NEXUS TEAM user verification uses Discord Linked Roles. This system lets users link roles to their Discord accounts and be verified automatically.

Verification Process:

  • The user clicks the Verify button in our Discord server.
  • Discord sends an HTTP request to this endpoint.
  • The server checks whether the user meets the verification requirements.
  • If the requirements are met, the verification role is assigned automatically.

Endpoint JSON Response

When Discord sends a request to this endpoint, the NEXUS TEAM server returns a JSON response in this format:

{
  "verified": true,
  "userId": "123456789012345678",
  "roleId": "987654321098765432",
  "timestamp": "2026-10-08T12:00:00Z",
  "team": "NEXUS TEAM"
}

Security and Privacy

NEXUS TEAM takes your data security and privacy seriously. During verification:

  • Only the data needed for verification is collected.
  • Your data is not shared with third parties.
  • You may request deletion of your data at any time.
  • Communication uses secure HTTPS connections.

Frequently Asked Questions

What happens if verification fails?

The user is notified automatically and can try again. If the problem continues, contact the NEXUS TEAM staff on Discord.

Can verification be removed after it is granted?

Yes. NEXUS TEAM administrators can remove verification at any time if a user breaks the server rules.
